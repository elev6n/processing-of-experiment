# Обработка лабораторного эксперимента

Приложение Python 3.11+ / PySide6 для прямых, косвенных и неравноточных измерений и линейного МНК.

## Быстрый старт: готовая программа

Для Windows 10/11 x64 скачайте `ExperimentProcessor.exe` из раздела
[Releases](../../releases/latest) этого репозитория и откройте файл двойным щелчком.
Установка Python и библиотек не требуется. При первом запуске распаковка во временную папку
может занять некоторое время.

Введите измерения в таблицу и нажмите «Рассчитать». Для расчёта по формуле перейдите
на вкладку косвенных измерений и выберите сохранённую величину или введите данные вручную.

## Основные экраны

Прямые измерения: серия наблюдений, таблица отклонений, погрешности и итоговая запись
с копированием текста или LaTeX.

![Прямые измерения с результатом расчёта](docs/screenshots/direct.png)

Косвенные измерения: формула, связанные исходные величины и аналитическое распространение
погрешности. В примере используется результат прямого измерения диаметра.

![Косвенные измерения со связанной величиной](docs/screenshots/indirect.png)

## Запуск в Windows

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

`gui_app.py` также запускает приложение.

## Локальная сборка EXE

Используйте Windows x64 и Python 3.11 x64. После создания окружения и установки
зависимостей, как описано выше, установите сборщик:

```powershell
.venv\Scripts\python.exe -m pip install pyinstaller pytest
```

Сборка одной командой из корня проекта:

```powershell
.venv\Scripts\python.exe build_exe.py
```

Результат: `dist/ExperimentProcessor.exe`. Скрипт удаляет прежние `build/` и `dist/`,
собирает приложение в режиме `--onefile --noconsole`, подключает Qt-плагины
`platforms` и доступные `styles`, нативные библиотеки NumPy/SciPy и скрытые импорты
SciPy/SymPy. Если существует `assets/icon.ico`, он используется как иконка EXE.
Matplotlib включён с QtAgg и данными шрифтов. Неиспользуемые Tkinter, IPython, pytest и альтернативные Qt-привязки исключены.
UPX отключён для совместимости нативных библиотек; отсутствие ложных срабатываний
антивирусов не гарантируется.

## Работа с интерфейсом

- На вкладке прямых измерений задайте символ, единицу, приборную погрешность и доверительную вероятность. Введите значения или скопируйте один столбец чисел без заголовка и нажмите Ctrl+V в таблице. Запятая, точка и научная запись поддерживаются. Пустые строки нужно заполнить или удалить.
- После расчёта справа появится таблица отклонений с объединёнными ячейками общих погрешностей, среднее, сумма квадратов и округлённая итоговая запись. Кнопки копируют текст или LaTeX.
- Каждый расчёт сохраняется в памяти под символом величины. Для следующей величины измените символ и данные; повторный расчёт того же символа обновляет сохранённый результат. Изменение исходных полей скрывает текущий вывод, но сохранённые результаты остаются доступны до закрытия приложения.
- На вкладке косвенных измерений введите формулу, например `m * v^2 / 2`. Поля переменных появляются автоматически. Выберите сохранённую величину в списке источников или введите среднее и абсолютную погрешность вручную. По умолчанию сохранённые среднее и погрешность округляются как в итоговой карточке; снимите флажок округления для расчёта с исходной точностью. Ручной ввод используется без изменений.
- Успешные косвенные расчёты тоже сохраняются в общем пуле: результат `V = S/t` можно выбрать источником для следующей формулы `V^2/2`. При совпадении символов используется последний успешный результат. Пул хранится до закрытия приложения; сохранённые результаты являются снимками и не пересчитываются автоматически при изменении исходных величин. Связанные поля обновляются при новом расчёте выбранного источника. Цепочки используют приближение независимых погрешностей; зависимости между величинами из общего исходного измерения не учитываются.
- Кнопка «Показать ход расчёта / формулы подстановки» открывает численную подстановку в исходную формулу, частные производные, их значения и вклады в абсолютную погрешность. Блок изначально скрыт; текст можно выделить и скопировать.
- На третьей вкладке «Неравноточные измерения» задайте символ и единицу результата. Добавляйте и удаляйте серии; для каждой введите среднее и строго положительную абсолютную погрешность либо выберите любой сохранённый результат: прямой, косвенный или неравноточный. Связанные поля заполняются автоматически и обновляются при новом расчёте источника.
- Как и в косвенных измерениях, флажок «Использовать округлённые значения сохранённых величин» включён по умолчанию: используются среднее и погрешность из итоговой карточки источника. Снимите флажок для полной сохранённой точности. В расчёт передаются именно числа из полей серии; ручной ввод не округляется в обоих режимах. Изменение режима скрывает текущий результат и ход расчёта; нажмите «Рассчитать» заново. Отключение округления не восстанавливает точность, потерянную при предыдущих расчётах по округлённым исходным данным.
- Кнопка «Показать ход расчёта / формулы подстановки» показывает режим точности, выбранные источники, фактические средние и погрешности, вычисление весов и вкладов, суммы, подстановки для взвешенного среднего, абсолютной и относительной погрешностей. Блок изначально скрыт; его текст можно выделить и скопировать.
- Объединение использует веса `w_k = 1/Δx_k²`, среднее `X = Σ(w_k·x_k)/Σw_k` и внутреннюю абсолютную погрешность `ΔX = 1/√Σw_k`. Относительная погрешность равна `ΔX/|X|·100%`; при нулевом среднем она не определена. Таблица показывает веса и процентные вклады, выделяя серии с наибольшим вкладом. Кнопки копируют итог и относительную погрешность в текст или LaTeX.
- Результат неравноточного расчёта автоматически сохраняется в общем пуле и доступен в источниках косвенных измерений до закрытия программы. Повторный расчёт того же символа заменяет предыдущее значение. При объединении используйте независимые серии одной величины с согласованными единицами и сопоставимым смыслом погрешностей. Оценка внешнего разброса и поправка Стьюдента для объединения не применяются.
- Единицы не преобразуются автоматически. Используйте согласованные единицы; погрешности считаются независимыми. Тригонометрические функции принимают радианы.
- Ошибки вычисления показывают понятное сообщение, разворачиваемые технические детали и кнопку копирования отчёта с исходными данными.

Вычисления и разбор формулы выполняются в фоне. Промежуточные данные показываются с восемью значащими цифрами, итог округляется по правилам `calc_engine.round_measurement`. Нулевая приборная погрешность разрешена движком. Поля `std_dev` и `std_error` существующего движка оба содержат стандартную ошибку среднего; интерфейс указывает это явно.

## Метод наименьших квадратов

Четвёртая вкладка строит зависимость `y = kx + b`. Введите минимум три пары X/Y;
числа разделяются пробелами, точкой с запятой или переводами строки. Десятичная запятая,
точка и научная запись допустимы. Для каждой оси можно задать одну общую либо N
неотрицательных погрешностей. Пустое поле означает отсутствие крестов по этой оси.

В режиме памяти выбирайте один или несколько источников через Ctrl/Shift. Прямой результат
даёт исходные наблюдения с приборной погрешностью каждой точки; погрешность среднего
не переносится на отдельные наблюдения. Косвенные, неравноточные результаты и коэффициенты
МНК дают одно среднее с его абсолютной погрешностью. Источники объединяются в порядке
списка, X и Y сопоставляются по позиции. Задавайте подписи осей (например, `Время $t$`)
и согласованные единицы самостоятельно. MathText работает без установленного TeX.

Используется обычный невзвешенный МНК: погрешности точек отображаются на графике,
не меняя веса или наклон. `s² = Σ(yᵢ − kxᵢ − b)²/(N−2)`,
`Δk = s/√Σ(xᵢ−x̄)²`, `Δb = s·√(1/N + x̄²/Σ(xᵢ−x̄)²)`.
Это стандартные ошибки (1σ), без множителя Стьюдента. При одинаковых X расчёт невозможен;
при постоянном Y коэффициент Пирсона не определён. Нулевые ошибки точек допустимы.

Коэффициенты автоматически сохраняются под разными редактируемыми символами (по умолчанию
`k`, `b`) и доступны в косвенных формулах. Единица наклона — Y/X, смещения — Y.
Расчёт хранит полную точность, карточка округляет результат. Как и в остальном пуле,
последний расчёт символа заменяет прежний; ковариация между k и b при последующих
косвенных расчётах не учитывается. Изменение данных очищает текущий график,
но сохраняет снимки коэффициентов в памяти.

Панель Matplotlib позволяет масштабировать график и перемещаться по нему.
Кнопка «Сохранить график» экспортирует PNG (200 dpi) или PDF для отчёта.

Новые модули: `least_squares.py` — расчёты без GUI,
`widgets/least_squares_tab.py` — ввод данных, график и интеграция с памятью.
